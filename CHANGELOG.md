All notable changes. Versions follow semver. The sensor catalog has its own version
(`ecowitt_catalog.json` → `catalog_version`, `schema_version`).

## 0.1.0 – 2026-11 (unreleased)

First version. Implements variant A of the plan (adapting S2 code, see
[docs/plans](docs/plans)).

### Modifications to upstream code (GPLv3 §5a)

Modified by mKainzbauer, 2026-11. Based on weewx-EcowittGateway (Ian Millard) at commit
`5cbe533`:

- The single-file driver is split into modules (`util`, `units`, `sources/parser`,
  `sources/http_api`, `mapping`, `history/cloud`, `history/sd`).
- Unit registration moved from module level into functions/constructors.
- `EcowittHttpApi`/`EcowittDevice`: the host may contain a port; `EcowittSensors` removed.
- `EcowittHttpCollector`: replaced by one polled `HttpSource` per gateway (no thread); sensor
  info cached for `sensors_interval`.
- `EcowittDeviceCatchup`: SD port configurable (`sd_port`); device/opener injectable; files
  that do not start with `YYYYMM` are skipped.
- `EcowittNetCatchup`: request timeout; opener injectable.
- `OnceLogger`: name prefix. `mask_secrets`: also masks `passkey`.
- `DeltaTracker` semantics reused in `cumulative.py` for several sources.
- ConfEditor: the structure is kept; prompts and the stanza are new.

### New

- Several sources (HTTP, MQTT) with priority merge per field and fallback.
- Arbitration of cumulative counters across sources.
- Outage detection with engine restart and catchup from SD/Ecowitt.net, merged by priority.
- Versioned sensor catalog (1.0.0, schema version 1.0.0) generated by
  `tools/build_catalog.py`.
- Handling of unknown keys; Ecowitt schema; `EcowittSchemaService` to add columns.
- MQTT source for the native gateway export and ecowitt2mqtt.
- Configurator: `--sources`, `--live-data`, `--dump-api`, `--history`, `--sd-files`,
  `--unknown-fields`, `--export-mqttsubscribe`, `--check-schema`, `--add-columns`.
- Tests with synthetic fixtures.
